# Brand, Namespace & Trademark Notes

## 1. Brand Context & Namespace Review

The project name **StackLift** communicates an active engineering metaphor: "lifting" legacy technology stacks to modern standards without high-risk total rewrites.

However, a landscape search reveals existing commercial entities and namespace reservations using the name:

| Entity | Domain / Namespace | Focus Area | Collision Severity |
| :--- | :--- | :--- | :--- |
| **Stacklift.io** | `stacklift.io` | AWS Cloud Infrastructure automation tool | Medium |
| **Stacklift.ai** | `stacklift.ai` | Enterprise software delivery / AI consultancy | High |
| **PyPI `stacklift`** | Python Package Index | CLI tool for AWS CloudFormation management | Medium |

---

## 2. Implications & Strategic Options

### Option A: Retain "StackLift" for Hackathons, Student & Portfolio Use
- **Viability**: Acceptable for internal hackathons, research prototypes, and personal portfolio showcases.
- **Guideline**: Add clear disclaimer: *"StackLift is an experimental open-source research prototype for Java application modernization, unaffiliated with StackLift Inc. or stacklift.io."*

### Option B: Pivot Name for Commercialization
Alternative names: **ModerniStack**, **LiftBridge**, **RefactorForge**, **RelicLift**, **AppTranscend**.

---

## 3. Brand Consistency Guidelines

- **Core Tagline**: *Lift Legacy. Build Forward.*
- **One-Sentence Description**: *"StackLift is an AI-assisted engineering platform that helps developers understand legacy applications, plan and apply supported modernization changes, and validate those changes through reproducible, evidence-backed workflows."*
